# Peirce Quincuncial SVG Converter

Illustrator 由来の 2:1 正距円筒 SVG を、Peirce quincuncial の正方形 SVG に変換するローカルアプリです。

要点:

- ラスタライズしません。地図本体は SVG パスのまま再生成します。
- 文字は `text/tspan` のまま残し、位置だけ投影します。
- 同じ地図を何度でも再変換できるように、Web UI と CLI の両方を用意しています。
- 既定の `lon_0` は `81` です。

## 使い方

### Web UI

```bash
npm install
npm run dev
```

起動後、ブラウザで表示された画面に SVG をドラッグするか、`同梱サンプルを使う` を押してください。

### CLI

```bash
npm run transform -- "イラレ出界図.svg" "out/イラレ出界図_peirceq_lon081.svg"
```

主なオプション:

```bash
--lon0=81
--sample-step=3
--path-precision=0.35
--side=4249.288
```

## 実装メモ

- 元の地図フレームは、もっとも大きい 2:1 の `rect` を基準に検出します。
- 背景フレーム `rect` は投影せず、出力側の正方形背景 `rect` に置き換えます。
- パスや直線はサンプリングしてから投影し、出力も SVG パスとして保存します。
- 文字はアンカー位置のみ投影し、`text` 自体はベクタ編集可能なまま残します。

## 注意

- 文字の回転や細かな位置合わせは自動では完全一致しません。想定通り、後で SVG 編集ソフト側で微調整してください。
- `defs` 内の複雑な図形参照やクリップが新しい元データで増えた場合は、その部分だけ追加対応が要る可能性があります。
